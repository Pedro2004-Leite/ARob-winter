# AI-solutions

Esta pasta contém **AI-solutions**: soluções geradas por um agente de IA (Claude, Anthropic) para as questões teóricas do `26_27_AR_Lab1.pdf`.

Não são soluções oficiais nem foram revistas por um docente.
Servem apenas de referência para comparação com o trabalho feito no papel.
Podem conter erros, sobretudo em convenções de sinal que dependem da numeração exacta dos rotores.

## Conteúdo

- `AI-solutions-lab1-2.1-2.3.tex` - resolução das questões 2.1, 2.2 e 2.3 (Secção 2, Modelação) do guião deste ano. Compilar em Overleaf (ou `pdflatex`) para obter o PDF a comparar com a resolução manual.

## Como usar

À medida que novas alíneas forem resolvidas no papel, pedir para acrescentar a alínea correspondente a este ficheiro (ou criar um novo `AI-solutions-lab1-X.tex`) e comparar.
